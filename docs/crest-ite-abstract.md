# ITE abstract draft

**Title**

Distinguishing a missing freeway detector reading from emerging congestion

**Track**

Transportation Operations

When a freeway detector stops reporting, an operator needs to know what the neighboring stations saw. The replay shows the last good five-minute reading and its age alongside the detector's neighbors. It suggests checking the detector when those stations remain clear and checking for a queue when they report concurrent low speeds. It marks cases with too little evidence as unavailable.

On southbound I-880, an injected outage prompted a detector check. A separate low-speed window prompted a queue check. Across 58 archived fault cases and 468 scored target instances, graph reconstruction reduced speed MAE from 5.86 to 4.65 km/h. Both methods missed all ten low-speed queue-proxy positives. The demonstration lets attendees trace a proposed action to the readings available at the time and score a missing estimate against the original observation. [Evaluation](crest-evaluation.md)
